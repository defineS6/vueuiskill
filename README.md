# vue-ui-consistency

给 AI 编码助手（Pi、Claude Code 等）用的 Skill：在 Vibe Coding（AI 辅助快速开发）中，让 Vue 项目跨多轮对话后仍然保持统一的视觉与交互。

## 解决什么问题

用 AI 一轮一轮加页面，最容易出现的毛病是「每个页面像不同人写的」：A 页面写死一套色值和圆角，B 页面又换一套间距和按钮写法，C 页面自己用 `div` 手搓了一个跟全局不一样的弹窗。

这个 Skill 让助手在动手写 `<template>` 和 `<style>` 之前，先读项目已有的视觉规则；没有规则时先建立最小公共变量，再写业务页面。

## 目录结构

```
SKILL.md                        主规则（助手加载入口）
references/DESIGN-template.md   项目设计记忆模板，落地成项目根目录的 DESIGN.md
references/tokens-template.css  基础 CSS 变量模板（颜色/圆角/间距/字号）
README.md                       本文件
```

## 使用方法

把整个目录放进你的 skills 目录即可，助手在遇到「开发 / 美化 / 重构 Vue 页面」「统一前端视觉风格」这类需求时会自动加载：

- Pi：`~/.pi/agent/skills/vue-ui-consistency`
- Claude Code：`~/.claude/skills/vue-ui-consistency`

也可以直接把 `SKILL.md` 的内容贴进系统提示词或项目级规则文件。

## 规则要点

适用任何风格的 Vue 项目（极简、毛玻璃、企业后台都行，不绑定具体 UI 库），核心是五条铁律：

1. **不写死魔术值**：颜色、圆角、阴影、字号来自全局变量或组件库令牌，业务组件里不出现随手写的 `#xxx`。
2. **优先复用公共组件**：同一种控件全项目只有一种长相，弹窗、表格、空状态先找现成封装。
3. **骨架对齐样板页**：外层留白、标题栏高度、按钮主次与顺序、筛选排布，对照项目里已有的同类页面。
4. **几何关系自洽**：内层圆角不大于外层圆角；同级元素边框阴影一致；浮动层阴影明显高于静态卡片。
5. **状态与细节统一**：异步四态（加载 / 空 / 报错 / 正常）统一表现，`focus-visible` 不留焦点残留，数字用等宽字形，长文本省略。

另外附带了 Element Plus 项目里两个高频坑的具体写法：`el-dialog` 的双层留白与首屏截断、`el-drawer` 的双层分割线与高度撑满。

交付前还有一份 6 项自检清单，避免「规则写了但没照做」。
