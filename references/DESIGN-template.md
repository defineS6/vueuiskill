# DESIGN.md — 项目视觉与交互规范（模板）

> 用途：供开发者与 AI 助手在跨会话开发时保持全站 UI 一致。
> 原则：只记录真相源文件路径、视觉基调、公共组件清单与硬性布局规则，控制在 120 行以内；具体色值以样式代码文件为准，不在本文档重复抄写第二份色表。

## 1. 真相源文件路径（Sources of Truth）

| 职责 | 文件路径 | 说明 |
| --- | --- | --- |
| 全局设计变量（颜色/圆角/字号/间距） | `src/styles/tokens.css` | 所有组件只引用这里的 CSS 变量，禁止写死色值 |
| UI 组件库 / Tailwind 配置 | `src/main.ts` / `tailwind.config.js` | 组件库主题覆盖与预设类名 |
| 公共基础组件目录 | `src/components/common/` | 弹窗、表格、工具栏、空状态、标签等 |
| 布局样板页面 | `src/views/xxx/Index.vue` | 新增同类页面时对照此页面的外框留白与结构 |

## 2. 视觉基调与主题模式

- **整体风格**：（例如：清爽企业后台 / 流体毛玻璃 Bento / 极客高密度控制台）
- **主题模式**：（明确写清：仅单套浅色主题 / 仅单套深色主题 / 支持浅色与深色切换 / 支持多风格切换）
- **字体与数字**：
  - 界面正文：`var(--font-sans)`
  - 代码与编号：`var(--font-mono)`
  - 凡是金额、数量、耗时、页码、表格数值列，统一加 `.tabular-nums`（`font-variant-numeric: tabular-nums`）。

## 3. 空间布局与几何层级

- **页面外框**：主工作区统一内边距 `24px`（移动端 `12px`），最大宽度 `1440px`（或铺满视口）。
- **圆角递减阶梯**（内层圆角不得大于外层容器）：
  - 外层大面板 / 弹窗：`12px`（`var(--radius-lg)`）
  - 常规卡片 / 数据表格：`8px`（`var(--radius-md)`）
  - 按钮 / 输入框 / 下拉框：`6px`（`var(--radius-sm)`）
  - 状态标签 / 小徽章：`4px`（`var(--radius-xs)`）
- **表面与阴影边界**：
  - **静态表面（卡片、表格、侧边栏）**：使用背景色阶差 + `1px solid var(--border-main)` 细边框（根据项目风格决定是否带微弱底影）。
  - **浮动表面（弹窗、抽屉、下拉菜单、气泡提示）**：必须叠加 `1px` 边框与悬浮阴影 `var(--shadow-float)` / `var(--shadow-overlay)`。

## 4. 必须复用的公共组件清单

写新页面前先用下列组件，禁止在业务页面里用 `div` 重新手搓：

- **页面头部与工具栏**：`<PageHeader>` / `<Toolbar>`（左标题或页签，右搜索框与主操作按钮；筛选项超过 4 个时收进折叠面板）
- **数据表格**：`<AppTable>`（开启 `table-layout: fixed`，长文本单行省略 `truncate`）
- **弹窗与抽屉**：`<AppModal>` / `<AppDrawer>`（底部按钮固定“左取消、右确认”）
- **状态标签**：`<StatusTag>`（软底色 + 圆点指示器，不仅靠颜色区分状态）
- **空状态与加载**：`<EmptyState>`（列表为空时统一展示图标 + 一句话说明 + 操作按钮）

## 5. 交互与防崩坏红线

1. **防点击焦点残留**：鼠标点击按钮或链接不显示焦点框，统一使用 `:focus-visible`；新窗口链接（`target="_blank"`）点击后自动 `blur()`。
2. **主次按钮克制**：同一视图区域最多只有 1 个主色填充按钮（Primary），危险操作（删除/清空）必须经过二次确认并指明操作对象名称。
3. **数据刷新不跳动**：初次加载用骨架屏；刷新已有数据时保留原列表几何高度，仅显示局部加载状态，禁止整页闪白。
